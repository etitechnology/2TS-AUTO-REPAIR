# 2 T's Auto Repair

A professional auto repair shop website featuring service information, trust badges, and location details.

## GitHub Pages Deployment

This site is configured to automatically deploy to GitHub Pages when changes are pushed to the `main` branch.

### Setup Instructions

To enable GitHub Pages for this repository:

1. Go to your repository on GitHub
2. Navigate to **Settings** > **Pages**
3. Under **Source**, select **GitHub Actions**
4. The workflow will automatically deploy the site when changes are merged to `main`

The site will be available at: `https://etitechnology.github.io/2TS-AUTO-REPAIR/`

### Manual Deployment

You can also trigger a deployment manually:

1. Go to **Actions** tab in your repository
2. Select the **Deploy to GitHub Pages** workflow
3. Click **Run workflow**
